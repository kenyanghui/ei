一、什么是 AI 技能包

AI 技能包（Skill Pack）是为 AI Agent（如 Claude Code）设计的专业技能模块。每个技能包封装了一套完整的知识框架、工作流程和实践工具。

技能包结构

ei-self-awareness-coach/
├── SKILL.md              ← 技能定义、工作流程、边界条件
└── test-prompts.json     ← 测试触发词和期望响应

SKILL.md 包含

  • 触发条件：哪些用户输入应该激活本技能
  • 核心工作流程：AI 被激活后应遵循的步骤
  • 知识框架：核心理论和模型
  • 工具库：AI 可以调用的具体工具和方法
  • 边界条件：什么情况下不适用
  • 输出格式：期望的输出结构

技能包如何工作

  1. 匹配触发词：AI 将用户输入与已安装技能包的触发条件匹配
  2. 激活技能：匹配成功后 AI 加载对应 SKILL.md 作为上下文
  3. 按框架执行：遵循工作流程和工具库响应
  4. 输出结果：按定义格式呈现
核心原则：技能包是框架，不是脚本。AI 在框架内仍有灵活性；教练在 AI 输出基础上仍有判断权。

二、安装指南

方法一：自动安装（推荐）

curl -fsSL https://ei2026.netlify.app/skills/install.sh | bash

方法二：手动安装单个

mkdir -p ~/.claude/skills/
curl -LO https://ei2026.netlify.app/skills/ei-self-awareness-coach.tar.gz
tar -xzf ei-self-awareness-coach.tar.gz -C ~/.claude/skills/
# 验证
ls ~/.claude/skills/ei-self-awareness-coach/
# 输出：SKILL.md  test-prompts.json

方法三：批量安装全部 13 个

SKILLS=(
  ei-self-awareness-coach ei-resonant-leadership
  ei-emotional-reasoning ei-stress-resilience
  ei-workplace-positive-influence ei-multiple-intelligences
  ei-cert-meta-skill ei-goleman-eq4 ei-goleman-6-leadership
  ei-msceit ei-eq-i ei-genos-six-dimensions
)
mkdir -p ~/.claude/skills/
for skill in "${SKILLS[@]}"; do
  echo "安装: $skill"
  curl -fsSL "https://ei2026.netlify.app/skills/${skill}.tar.gz" \
    | tar -xz -C ~/.claude/skills/
done
echo "✅ 全部安装完成"

验证安装

for skill in ~/.claude/skills/ei-*/; do
  name=$(basename "$skill")
  if [ -f "$skill/SKILL.md" ]; then echo "✅ $name"; else echo "❌ $name"; fi
done

功能验证

在 AI Agent 中输入："情绪很乱，帮我分析一下"。应返回情绪标注→逻辑链追溯→模式识别。

三、Genos 认证技能包（7 套）

3.1 ei-self-awareness-coach

项目内容
对应维度Genos 维度 1：情绪自我觉察
难度⭐ 入门级
触发词"情绪很乱" "帮我分析感受" "不知道为什么很烦躁"

工作流：情绪标注 → 逻辑链追溯（事件→感受→情绪→想法→行为→结果）→ 模式识别 → 行动计划

3.2 ei-resonant-leadership

项目内容
对应维度Genos 维度 6：积极影响力（领导力）
难度⭐⭐⭐ 进阶级
触发词"团队士气低落" "如何领导" "新晋管理者怎么带团队"

工作流：情境诊断 → 六种领导力风格评估 → 共鸣策略匹配 → 行动规划

3.3 ei-emotional-reasoning

项目内容
对应维度Genos 维度 4：情绪推理
难度⭐⭐ 中级
触发词"无法决定" "直觉与逻辑冲突" "应该选 A 还是 B"

工作流：四象限矩阵（事实数据 × 情绪信息）→ 数据收集 → 情绪收集 → 整合分析 → 决策输出

3.4 ei-stress-resilience

项目内容
对应维度Genos 维度 5：自我管理
难度⭐⭐ 中级
触发词"压力太大" "焦虑" "burnout" "失眠" "如何放松"

工作流：压力评估 → 即时调节（4-7-8呼吸/STOP法/接地技术）→ 认知重构 → 韧性规划

⚠ 安全边界：仅适用于日常压力和轻度焦虑。如用户表达自伤/自杀意念、持续两周以上严重困扰、无法日常功能，应输出转介建议。

3.5 ei-workplace-positive-influence

项目内容
对应维度Genos 维度 6：积极影响力（协作）
难度⭐⭐⭐ 进阶级
触发词"同事不配合" "跨团队协作" "冲突处理" "如何给反馈"

工作流：关系诊断（情感账户审计）→ 策略选择（共情→利益→证据→行动）→ SBI 反馈准备 → 行动计划

3.6 ei-multiple-intelligences

项目内容
对应维度Genos 维度 1 延伸（多元智能视角）
难度⭐ 入门级
触发词"不知道擅长什么" "发现天赋" "我的优势是什么"

工作流：八维探索（语言·逻辑·音乐·身体·空间·人际·内省·自然）→ 优势组合识别 → 应用建议

3.7 ei-cert-meta-skill

项目内容
类型元技能—覆盖全部 Genos 六维
难度⭐ 导航级
触发词"想了解 EI 认证" "认证路径" "EI 发展路线图"

工作流：需求诊断 → 路径推荐（Foundation→Practitioner→Senior→Master）→ 维度匹配 → 下一步行动

认证路径

📖 Foundation → 🛠 Practitioner → ⭐ Senior Practitioner → 👑 Master
   觉察             应用                 精通                  赋能
   "是什么"         "怎么做"            "教别人"              "推动改变"
级别核心要求时间跨度
Foundation理解六维模型 + 360° 自评 + 发展计划1-2 个月
Practitioner360° 反馈解读 + 90 天行为改变3-6 个月
Senior Practitioner辅导他人 + 案例分析6-12 个月
Master主导转型项目 + 组织文化12-24 个月

四、理论蒸馏技能包（6 套）

AI 蒸馏不是复制话语，而是提炼思维框架。将六位 EI 理论家的核心著作提取为 AI 可直接运行的思维框架。

技能包 8：ei-goleman-eq4

学者：戈尔曼 | 框架：自我觉察→自我管理→社会觉察→关系管理 | 工具：STOP 法、NVC、共情四层次

技能包 9：ei-goleman-6-leadership

学者：戈尔曼 | 框架：六种领导力风格（指令·愿景·亲和·民主·领跑·教练） | 工具：情境-风格矩阵

技能包 10：ei-msceit

学者：梅耶 & 萨洛维 | 框架：感知→促进→理解→管理 | 工具：情绪词汇表、情绪逻辑链

技能包 11：ei-eq-i

学者：巴昂 | 框架：五因素（自我认知→自我表达→人际→决策→压力管理） | 工具：4-7-8 呼吸法、认知重构三步法

技能包 12：ei-genos-six-dimensions

学者：Palmer & Stough | 框架：六维职场行为频率 | 18 项行为指标（每维度 3 项）

技能包 13：ei-multiple-intelligences

学者：加德纳 | 框架：八种智能组合 | 与认证技能包 6 功能相同

五、使用最佳实践

触发策略

方式示例效果
直接触发"情绪很乱，帮我分析一下"精确命中
间接"我最近总觉得不对劲"语义匹配
混合"作为技术经理，团队士气低落"触发领导力+场景上下文

推荐组合

场景组合
团队士气低谷ei-resonant-leadership + ei-workplace-positive-influence
个人职业发展ei-multiple-intelligences + ei-self-awareness-coach + ei-cert-meta-skill
冲突调解ei-emotional-reasoning + ei-workplace-positive-influence

教练工作流中的 AI 定位

✅ 正确：客户 → 教练（倾听+判断）→ AI（技能包提供框架）→ 教练（整合判断）→ 客户
❌ 错误：客户 → AI（直接回答）→ 客户

六、自定义技能包开发

# 创建新技能包
mkdir -p ~/.claude/skills/my-ei-custom-skill/

# 从现有技能包复制（推荐）
cp -r ~/.claude/skills/ei-self-awareness-coach ~/.claude/skills/my-adapted-coach

# 修改 SKILL.md：名称/描述/触发词/工作流/工具库

# 打包分享
tar -czf my-custom-skill.tar.gz -C ~/.claude/skills/my-custom-skill/ .

七、常见问题

问题解决方案
技能包没有被激活检查安装路径；使用标准触发词；更新 AI Agent 版本
AI 输出与预期不符提供更多上下文；明确指定想用的技能包；检查 SKILL.md 格式
安装权限错误sudo chown -R $(whoami) ~/.claude/
